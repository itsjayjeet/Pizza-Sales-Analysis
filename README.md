# 🍕 Pizza Sales Analysis Dashboard

An interactive **Pizza Sales Dashboard** developed using **SQL and Power BI** to analyze pizza sales performance, revenue trends, order behavior, and best- and worst-selling pizzas.

## Dashboard Preview

![Pizza Sales Dashboard](dashboard_screenshot.png)

## Project Overview

This project provides a detailed analysis of pizza sales data through an interactive Power BI dashboard. It helps understand overall business performance, sales trends, customer ordering behavior, and product performance.

## Tools and Technologies

* **SQL / PostgreSQL** – Data querying and analysis
* **Power BI** – Dashboard development and visualization
* **CSV** – Dataset

## Dashboard Pages

### 1. Home Page

The Home page provides an overview of the business performance through important KPIs and charts.

#### Key Performance Indicators

* Total Revenue
* Average Order Value
* Total Pizzas Sold
* Total Orders
* Average Pizzas Per Order

#### Visualizations

* Daily Trend for Total Orders
* Monthly Trend for Total Orders
* Percentage of Sales by Pizza Category
* Percentage of Sales by Pizza Size
* Total Pizzas Sold by Pizza Category

### 2. Best/Worst Page

The Best/Worst page focuses on product-level performance and helps identify the best- and worst-performing pizzas.

This page can be used to understand:

* Top-selling pizzas
* Low-performing pizzas
* Product-wise sales performance
* Category-wise product contribution

## Dashboard Filters

The dashboard includes interactive filters such as:

* Pizza Category
* Date Range

These filters allow users to analyze sales performance for a specific category or time period.

## Business Questions

* What is the total revenue generated?
* What is the average order value?
* How many pizzas were sold?
* How many orders were placed?
* Which day has the highest number of orders?
* Which month has the highest sales?
* Which pizza category contributes the most to sales?
* Which pizza size is most popular?
* Which pizzas are the best and worst performers?

## Key Insights

* The dashboard tracks overall revenue, order volume, and pizza sales using KPI cards.
* Monthly and daily trends help identify high-demand sales periods.
* Pizza category and size analysis shows customer preferences.
* The Best/Worst page helps identify products that perform well and products that may need improvement.
* Interactive filters make it easier to compare sales performance across categories and dates.
